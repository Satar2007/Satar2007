# SATAR2007 Profile Setup — V2 Full Futuristic Gaming

This repository is the profile repository for **Satar2007**.

## Included modules

- `README.md` — main GitHub profile presentation.
- `assets/header-satar-v2.svg` — animated hero header.
- `assets/control-deck-v2.svg` — animated control deck overview.
- `assets/energy-divider-v2.svg` — animated divider used between sections.
- `assets/footer-satar-v2.svg` — animated closing banner.
- `assets/generated/metrics.svg` — GitHub Metrics output generated by workflow.
- `assets/generated/isocalendar.svg` — full-year isometric contribution calendar.
- `assets/generated/skyline.gif` — animated contribution skyline.
- `assets/generated/pacman-contribution-graph*.svg` — contribution arcade.

## Workflows

### 1) Profile - Metrics
Generates:
- `assets/generated/metrics.svg`
- `assets/generated/isocalendar.svg`

**Required secret:** `METRICS_TOKEN`

Recommended token scopes:
- `public_repo`
- `read:user`

### 2) Profile - Pac-Man
Generates the Pac-Man contribution graph in dark and light mode.

### 3) Profile - Rotating Skyline
Renders the animated skyline using the GitHub contribution calendar.

### 4) Profile - Validate UI
Validates the README references and parses SVG assets to catch broken files early.

## Notes

- All animated profile visuals are implemented with **SVG / GIF**, making them compatible with GitHub README rendering.
- No client-side JavaScript is required.
- The skyline renderer is intentionally local and deterministic after fetching contribution data.

## How to use

1. Push this repository to `Satar2007/Satar2007`.
2. Add the `METRICS_TOKEN` repository secret.
3. Run the workflows manually once if the generated assets have not appeared yet.
4. Check the profile README preview on the repository homepage.
